# Natalie's Dashboard

## Project Description

Natalie's Dashboard is a small, responsive weather dashboard built with semantic HTML, CSS custom properties, and vanilla JavaScript. It includes a persistent light/dark theme toggle and loads sample weather data from a local JSON file.

## Features

- Light and dark themes with a saved preference
- Accessible theme toggle in the page header
- Weather widget populated from `data/weather.json`
- Responsive layout with focus-visible states

## Technologies

- HTML5
- CSS3 custom properties
- Vanilla JavaScript
- GitHub Pages

## Live Site

The dashboard is published at: https://nataliemagee13.github.io/dashboard/

## Local Development

Serve the project with a local web server so the weather JSON can load, for example:

```text
python3 -m http.server
```

Then open `http://localhost:8000/` in a browser.
